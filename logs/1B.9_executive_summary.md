## ✅ Root Cause Identified

**Primary Cause:** `volume_ratio` feature in `extract_features()` produces **NaN** values.

**Evidence from Debug Logs:**
```
[DEBUG-SIGNATURE] Estado 0:
  volume_ratio=nan  ← CRITICAL BUG
```

**Why This Breaks Pattern Discovery:**
1. NaN in SHA256 hashing → every state gets unique signature
2. Unique signatures → no pattern collisions → support = 1/N
3. Support < 3% min_support → patterns discarded
4. Result: emergent_patterns = 0

**Contributing Factors:**
- **H1:** Insufficient history per regime (~50 states vs. ~500 needed)
- **H5:** Test uses step=5, accumulating only 20% of possible history

## 🔧 Recommended Fixes (Phase 1B.10)

### Fix 1: NaN in volume_ratio (CRITICAL)

**File:** `src/python/market/structural_induction.py:184`

**Change:**
```python
# BEFORE (buggy):
features['volume_ratio'] = current_volume / np.mean(volumes[-20:]) if len(volumes) >= 20 else 1

# AFTER (fixed):
avg_volume = np.mean(volumes[-20:]) if len(volumes) >= 20 else current_volume
features['volume_ratio'] = current_volume / max(avg_volume, current_volume * 0.01)
```

**Expected Impact:** emergent_patterns: 0 → ≥10

### Fix 3: NaN Fallback (MEDIUM)

**File:** `src/python/market/structural_induction.py`

**Add after extract_features():**
```python
# Validate features against NaN/Inf
for key, value in features.items():
    if isinstance(value, float) and (np.isnan(value) or np.isinf(value)):

```

**Expected Impact:** Robustness against future NaN bugs
