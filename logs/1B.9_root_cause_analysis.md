### 1.2 Root Cause Statement

> "El feature `volume_ratio` en `extract_features()` produce valores **NaN** cuando el volumen promedio es 0 o muy cercano a 0. Esto causa que todos los signatures se vuelvan únicos (NaN != NaN en hashing), impidiendo que patrones emergentes alcancen el soporte mínimo requerido. Adicionalmente, el historial acumulado por régimen es insuficiente (~50-100 estados/régimen vs. ~500-1000 necesarios)."

## 4. Root Cause Identification

### 4.1 Primary Cause (Causa Raíz Primaria)

**Feature `volume_ratio` produce NaN**

**Ubicación:** `src/python/market/structural_induction.py`, línea 184

**Código Problemático:**
```python
features['volume_ratio'] = current_volume / np.mean(volumes[-20:]) if len(volumes) >= 20 else 1
```

**Problema:**
1. Cuando `np.mean(volumes[-20:])` es 0 → división por cero → NaN
2. NaN en hashing SHA256: `hash(NaN) != hash(NaN)` (cada NaN produce hash diferente)
3. Resultado: signatures únicas incluso para estados idénticos
4. Sin colisiones de signature → soporte = 1/N → nunca alcanza min_support=3%

**Evidencia:**
- [DEBUG-SIGNATURE] muestra `volume_ratio=nan` en TODOS los estados logueados
- 118 signatures únicas para 47 estados (imposible sin bug)

---

### 4.2 Contributing Factors (Factores Contribuyentes)

**Factor 1: Historial insuficiente por régimen**

- Historial total acumulado: ~200 estados @ 1000 iteraciones
- Distribución por régimen: BULL ~24%, BEAR ~20%, LATERAL ~56%
- Estados por régimen: BULL ~48, BEAR ~40, LATERAL ~112
- Para min_support=3%, se necesitan ≥3 estados con misma signature
- Con ~50 estados/régimen, probabilidad de colisión es baja

**Factor 2: Step size muy grande en test**

- Test usa `step=5` (añade estado cada 5 iteraciones)
- Reduce acumulación de historial en 80%
- Debería usar `step=1` para máxima acumulación

**Factor 3: Patrones se pierden en post-procesamiento**

- [DEBUG-VARIANCE] muestra 76 patrones descubiertos internamente
- Resultados finales muestran emergent_patterns = 0
- Bug en validación axiomática o filtrado descarta todos los patrones

## 5. Recommended Fix

### 5.1 Immediate Action (Acción Inmediata)

**Fix 1: Corregir NaN en volume_ratio**

**Archivo:** `src/python/market/structural_induction.py`

**Código Actual (línea 184):**
```python
features['volume_ratio'] = current_volume / np.mean(volumes[-20:]) if len(volumes) >= 20 else 1
```

**Código Corregido:**
```python
# Feature 3: volume_ratio (volumen relativo)
avg_volume = np.mean(volumes[-20:]) if len(volumes) >= 20 else current_volume
# Evitar división por cero: usar mínimo de 1% del volumen actual
features['volume_ratio'] = current_volume / max(avg_volume, current_volume * 0.01) if len(volumes) >= 20 else 1.0
```

**Rationale:**
- `max(avg_volume, current_volume * 0.01)` asegura denominador > 0
- Si avg_volume es 0, usa 1% del volumen actual como mínimo
- Previene NaN y mantiene ratio significativo

---

**Fix 2: Reducir step size en test**

**Archivo:** `tests/test_multi_market_autonomous.py`

**Código Actual (línea ~147):**
```python
for i in range(20, len(state.market_states), 5):  # Step de 5 para velocidad
```

**Código Corregido:**
```python
for i in range(20, len(state.market_states), 1):  # 1B.10: Step=1 para máxima acumulación
```

**Rationale:**
- Step=1 acumula 5x más historial
- Con 1000 iteraciones: ~1000 estados vs. ~200 estados actuales
- Impacto en performance es mínimo (<1 segundo adicional)

**Fix 3: Añadir fallback para features vacíos**

**Archivo:** `src/python/market/structural_induction.py`


**Rationale:**
- Defensa en profundidad contra futuros bugs de NaN
- Asegura que signatures sean consistentes

## 8. Lessons Learned

### 8.1 De 1B.9

1. **[Debug logging es crítico]**: Sin [DEBUG-*] tags, root cause habría permanecido oculta
   - **Aplicación:** Mantener debug_mode=True hasta estabilización

2. **[NaN es silencioso pero fatal]**: NaN en features rompe hashing sin errores explícitos
   - **Aplicación:** Validar features contra NaN/Inf en extract_features()

3. **[Historial por régimen es diferente al total]**: 1000 estados totales ≠ 1000 estados/régimen
   - **Aplicación:** Monitorear historial por régimen, no solo total

4. **[Descubrimiento interno ≠ resultados finales]**: 76 patrones descubiertos pero 0 reportados
   - **Aplicación:** Debuggear discover_and_validate() completo, no solo find_emergent_patterns()

### 8.2 Para Futuras Iteraciones

1. **[Validar features antes de hashing]**: Añadir chequeo de NaN/Inf en calculate_signature()
2. **[Acumular historial agresivamente]**: step=1 debería ser default, no optimización
3. **[Logging de validación axiomática]**: Añadir [DEBUG-VALIDATION] para patrones descartados

### Appendix C: Código de Fix Completo

```python
# structural_induction.py - Fix completo

def extract_features(self, state: TimeSeriesState, index: int) -> Dict[str, float]:
    """Extraer características con validación NaN."""
    if index < 20:
        return {}

    closes = state.closes[max(0, index-50):index+1]
    highs = state.highs[max(0, index-50):index+1]
    lows = state.lows[max(0, index-50):index+1]
    volumes = state.volumes[max(0, index-50):index+1]

    if len(closes) < 20:
        return {}

    current_close = closes[-1]
    current_volume = volumes[-1]
    features = {}

    # Feature 1: return
    features['return'] = (closes[-1] - closes[-2]) / closes[-2] if len(closes) >= 2 else 0

    # Feature 2: volatility
    features['volatility'] = np.std(closes[-20:]) / np.mean(closes[-20:]) if len(closes) >= 20 else 0

    # Feature 3: volume_ratio (FIX: evitar NaN)
    avg_volume = np.mean(volumes[-20:]) if len(volumes) >= 20 else current_volume
    features['volume_ratio'] = current_volume / max(avg_volume, current_volume * 0.01)

    # Feature 4: momentum
    features['momentum'] = (closes[-1] - closes[-6]) / closes[-6] if len(closes) >= 6 else 0

    # Feature 5: range_position
    range_high = np.max(highs[-20:]) if len(highs) >= 20 else current_close
    range_low = np.min(lows[-20:]) if len(lows) >= 20 else current_close
    features['range_position'] = (current_close - range_low) / (range_high - range_low + 1e-8)

    # Validar NaN/Inf (defensa en profundidad)
    for key, value in features.items():
        if isinstance(value, float) and (np.isnan(value) or np.isinf(value)):
            features[key] = 0.0

    return features
```
