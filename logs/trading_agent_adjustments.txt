--------------------------------------------------------------------------------
File: src/python/market/meta/trading_meta_learner.py
Function: update_pattern_effectiveness()

BEFORE:
  - Signature: update_pattern_effectiveness(pattern_id, success: bool, ...)
  - Logic: Binary update (success=True → +δ⁺, success=False → -δ⁻)

AFTER:
  - Signature: update_pattern_effectiveness(pattern_id, pnl_pct: float, success_threshold: float = 0.0, ...)
  - Logic: Proportional update based on PnL magnitude
    * If pnl_pct > threshold: reward_factor = min(2.0, 1.0 + pnl_pct/0.03)

      → confidence -= δ⁻ × penalty_factor

RATIONALE: Enables granular learning based on PnL magnitude, not just binary success/failure
