## V. OPTIMIZACIÓN VARIACIONAL + FORWARD-FORWARD

### A. Función de Costo
```
C(Θ_e) = B_e + μ·(1-success_e)·B_max
J(Φ) = Σ_e C(Θ_e(Φ))
min_Φ J(Φ) sujeto a Φ ∈ Dom_admisible
```

### B. Principio de Mínima Acción Discreto
```
L(S_k, S_{k+1}) = α·C_comp + β·C_incert + γ·C_complej
J = Σ_k L(S_k, S_{k+1})
ϕ ← Π_Dom(ϕ - α·dJ/dϕ)
```

### C. Estimación de Gradiente (Decisión Q1: REINFORCE)
```
∂J/∂ϕ ≈ ∇_Φ log π_θ(a|S) · (G - b)          [REINFORCE - Q1 Confirmada]

Donde:
- π_θ(a|S) = softmax(score(a, Φ) / τ)
- G = costo_total_episodio = Σ_k L(S_k, S_{k+1})
- b = baseline (costo promedio reciente)

Módulos afectados:
- hierarchical_policy.py: select_option_softmax()
- evolutionary_solver.py: almacenar log_probs
- variational_meta_learner.py: compute_reinforce_gradient()
```

### D. Forward-Forward como Meta-Patrón (Decisión Q5, Q6, Q11)
```
ff_goodness(Layer_l)      ↔  mse_score(i,j)
ff_positive_pass(Data)    ↔  mse_resolución_éxito(B_e, success=true)
ff_negative_pass(Corrupt) ↔  mse_backtrack(B_e > umbral, success=false)
ff_update(w_l)            ↔  mse_update(E(pt), H(i,j), Φ)

% Invariante estructural (Decisión Q5):
∀x: (positive(x) → maximizar(score(x))) ∧ (negative(x) → minimizar(score(x)))

% Criterio de Activación (Decisión Q11):
estancamiento = (backtracks > 50) ∧ (prog_k = 0 por 10 iteraciones)
SI estancamiento: Ψ.activar_FF()
```

## VIII. MÉTRICAS DE VALIDACIÓN (Decisión Q10)

```
METRICA_VALIDACION_Ψ:
  % Componente 1: Complejidad Cristalizada
  complejidad_promedio = Σ(complejidad(pt) para pt en patrones_cristalizados) / N_cristalizados

  donde complejidad(pt) = número_de_predicados + número_de_variables + orden_lógico

  % Componente 2: Ahorro de Pasos
  ahorro_pasos = (pasos_sin_Ψ - pasos_con_Ψ) / pasos_sin_Ψ

  % Métrica Compuesta:
  rendimiento_Ψ = α·complejidad_promedio + β·ahorro_pasos

  % Valores Sugeridos:
  α = 0.4  (peso complejidad)
  β = 0.6  (peso ahorro)
  umbral_minimo = 0.15  (15% mejora neta)

  % Criterio de Éxito:
  SI rendimiento_Ψ > umbral_minimo:
    Ψ_validado ← true
  SINO:
    Ψ_validado ← false
    revisar_componentes_Ψ()
```
