    3. Learning Mechanism - REINFORCE Step-by-Step

    Phase 1: Episode Collection (per bar)

     1 for each bar t:
     2     1. Observe state S_t (price, volume, regime, indicators)
     3     2. Select strategy π_θ(a|S_t) via softmax with temperature τ
     4     3. Execute trade (if pattern match & confidence ≥ e_pt_trigger)
     5     4. Record: (strategy, log_prob, regime, patterns_used)

    Phase 2: PnL Attribution (at trade close)

      1 # TradingBotAutonomous._close_position()
      2 pnl_pct_decimal = last_trade.pnl_pct / 100.0  # Preserve magnitude
      3
      4 # Update pattern effectiveness (REINFORCE for patterns)
      5 pattern_db.update_pattern_effectiveness(
      6     pattern_id=last_trade.pattern_used,
      7     pnl_pct=pnl_pct_decimal,  # PnL-proportional (not boolean!)
      8     success_threshold=0.0
      9 )
     10
     11 # Record episode for policy update
     12 meta_learner.record_episode(
     13     strategy=strategy_used,
     14     log_prob=log_prob,
     15     regime=current_regime,
     16     patterns_used=[...],
     17     pnl=pnl_pct_decimal
     18 )

    Phase 3: Pattern Confidence Update (E(pt))

      1 # MarketPatternDatabase.update_effectiveness()
      2 if success (pnl > 0):
      3     self.confidence += delta_plus * reward_factor
      4     # reward_factor = min(2.0, 1.0 + pnl_pct / 0.03)
      5     # Example: +5% PnL → reward_factor = 2.67 → capped at 2.0
      6 else:
      7     self.confidence -= delta_minus * penalty_factor
      8     # penalty_factor = 1.0 + abs(pnl_pct) / 0.03
      9
     10 # Confidence floor (prevent degradation)
     11 self.confidence = max(0.10, self.confidence)
     12
     13 # Crystallization check
     14 if self.confidence >= 0.70:
     15     self.crystallized = True

    Phase 4: Policy Gradient Calculation (end of episode)

      1 # TradingMetaLearner.update_strategy_policy()
      2 # REINFORCE gradient: ∇_Φ J = Σ_t [∇_Φ log π_Φ(a_t|S_t) · (G_t - b)]
      3
      4 for strategy, episode in episodes_by_strategy.items():
      5     G_t = episode.pnl  # Return for this episode
      6     log_prob = episode.log_prob
      7
      8     # Gradient: increase probability of high-return actions
      9     gradient = log_prob * (G_t - self.baseline)
     10
     11     # Update strategy weight
     12     self.strategy_weights[strategy] *= (1.0 + learning_rate * gradient)
     13
     14     # Update baseline (moving average)
     15     self.baseline = baseline_decay * self.baseline + (1 - baseline_decay) * G_t

     2 meta_learner.save_policy("data/patterns/meta_policy.pkl")
