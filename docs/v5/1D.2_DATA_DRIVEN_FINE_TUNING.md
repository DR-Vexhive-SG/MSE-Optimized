### Step 2: Implement Emergent Pattern Persistence

**Current Behavior:**
- Emergent patterns discovered via structural induction
- Used for 1 episode
- Deleted if not crystallized

**Problem:**
- Patterns may need 2-3 episodes to prove themselves
- Premature deletion loses potential high-value patterns

**Proposed Behavior:**
```python
# Add to MarketStoredPattern
episodes_without_improvement: int = 0

# In update_effectiveness()
if confidence decreased:
    episodes_without_improvement += 1
else:
    episodes_without_improvement = 0

# In prune_low_confidence()
if pattern.is_soft and pattern.episodes_without_improvement >= 3:
    # Remove pattern (failed to prove itself)
    patterns_to_remove.append(pattern)
elif pattern.confidence >= 0.70:
    pattern.crystallized = True
    pattern.is_soft = False
    # Keep crystallized patterns permanently
```

**Expected Impact:**
- More emergent patterns reach crystallization
- Better pattern diversity
- Win rate +2-3pp from newly crystallized patterns

# Add to MarketStoredPattern
last_used_regime: Optional[str] = None
