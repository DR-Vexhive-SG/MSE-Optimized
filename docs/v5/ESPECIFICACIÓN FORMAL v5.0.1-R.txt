## V. OPTIMIZACIÓN VARIACIONAL + FORWARD-FORWARD

### A. Función de Costo
```
C(Θ_e) = B_e + μ·(1-success_e)·B_max
J(Φ) = Σ_e C(Θ_e(Φ))
min_Φ J(Φ) sujeto a Φ ∈ Dom_admisible
```

### B. Principio de Mínima Acción Discreto
```
L(S_k, S_{k+1}) = α·C_comp + β·C_incert + γ·C_complej
J = Σ_k L(S_k, S_{k+1})
ϕ ← Π_Dom(ϕ - α·dJ/dϕ)
```

### C. Estimación de Gradiente
```
∂J/∂ϕ ≈ (C(Φ+ε) - C(Φ-ε)) / 2ε          [Diferencias finitas]
O: ∇_Φ log π_θ(a|S) · G                  [REINFORCE] ✅ DECISIÓN Q1
O: SPSA para alta dimensionalidad
```

### D. Forward-Forward como Meta-Patrón (Nuevo)
