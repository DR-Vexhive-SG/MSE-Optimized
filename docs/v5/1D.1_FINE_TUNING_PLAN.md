**Priority:** ⭐⭐⭐ HIGH

### Action 2: Premium Position Sizing Tier

**Priority:** ⭐⭐ HIGH  
**Effort:** Low (parameter change)  
**Risk:** Low

#### Current State
```python
# Confidence-based position sizing (3 tiers)
if confidence >= 0.70:
    position_pct = 0.025  # 2.5%
elif confidence >= 0.60:
    position_pct = 0.020  # 2.0%
else:
    position_pct = 0.015  # 1.5%
```

#### Proposed Change
```python
# Confidence-based position sizing (4 tiers)
if confidence >= 0.80:
    position_pct = 0.030  # 3.0% - NEW PREMIUM TIER
elif confidence >= 0.70:
    position_pct = 0.025  # 2.5%
elif confidence >= 0.60:
    position_pct = 0.020  # 2.0%
else:
    position_pct = 0.015  # 1.5%
```

#### Rationale
- 76 patterns have confidence ≥0.70 (20.3% of database)
- cup_and_handle has 0.746 avg confidence - deserves premium sizing
- Better risk-adjusted returns by sizing up on highest confidence patterns

#### Expected Impact
- Increased returns on high-confidence trades
- Slightly higher variance (acceptable given edge)
- Expected win rate improvement: 1-2%

#### Implementation
```python
# File: src/python/trading/trading_agent.py
# Method: calculate_position_size() or similar

def calculate_position_size(self, pattern):
    confidence = pattern.confidence
    
    if confidence >= 0.80:
        return 0.030  # NEW: Premium tier
    elif confidence >= 0.70:
        return 0.025
    elif confidence >= 0.60:
        return 0.020
    else:
        return 0.015
```

#### Validation
- Run backtest with premium tier enabled
- Track PnL contribution from ≥0.80 confidence trades
- Monitor max drawdown (should not increase significantly)

### Action 3: Learning Rate Adjustment (δ⁺, δ⁻)

**Priority:** ⭐ MEDIUM  
**Effort:** Low (parameter change)  
**Risk:** Medium

#### Current State
```python
meta_params = {
    'delta_plus': 0.15,       # Learning rate for wins
    'delta_minus': 0.156,     # Forgetting rate for losses
    # δ⁻ > δ⁺ means faster forgetting than learning
}
```

#### Proposed Change
```python
meta_params = {
    'delta_plus': 0.20,       # Increased from 0.15
    'delta_minus': 0.156,     # Keep unchanged
    # Now δ⁺ > δ⁻ means faster learning than forgetting
}
```

#### Rationale
- Current asymmetry (δ⁻ > δ⁺) causes negative drift
- With 44.41% win rate, system needs stronger positive reinforcement
- δ⁺ = 0.20 provides 33% faster confidence building for wins
- Maintains δ⁻ = 0.156 to preserve good patterns

#### Expected Impact
- Faster convergence for winning patterns
- More patterns reaching crystallization threshold
- Potential for higher average confidence across database

#### Implementation
```python
# File: src/python/trading/trading_meta_learner.py
# Or wherever meta_params are initialized

self.meta_params = {
    'delta_plus': 0.20,   # Changed from 0.15
    'delta_minus': 0.156, # Unchanged
    # ... other params
}
```

#### Validation
- Monitor pattern confidence evolution over episodes
- Track crystallization rate (should increase)
- Verify no runaway confidence inflation (cap at 1.0)
