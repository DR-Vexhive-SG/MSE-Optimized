## 1. Pattern Calibration Details

### 1.1 NEOJPY BEAR Calibration (CRITICAL - 36.8% Win Rate)

**Root Cause Analysis (1C.7):**
- BEAR regime win rate: 36.8% (NEOJPY pair)
- TP/SL ratio 2:1 too conservative for counter-trend reversals
- Counter-trend moves require wider TP to capture full reversal

**1C.8 Calibration:**

```python
# File: src/python/market/market_pattern_database.py
# Patterns: breakdown_support, rally_resistance

# 1C.7 (Previous)

# TP/SL = 2.0

# 1C.8 (Current)

# TP/SL = 3.0 (more aggressive for reversals)
```

**Expected Impact:**
- Better risk/reward ratio (3:1 vs 2:1)
- Tighter stop-loss reduces losses on failed reversals
- Higher take-profit captures full reversal moves

### 1.2 XMRUSD/REPBTC LATERAL Calibration (HIGH PRIORITY - 41.2-44.4% Win Rate)

**Root Cause Analysis (1C.7):**
- LATERAL regime win rate: 41.2% (XMRUSD), 44.4% (REPBTC)

- TP 3% still not reached consistently in tight ranges

**1C.8 Calibration:**

- Lower TP target increases win frequency
- Better suited for tight range-bound markets
